# Dcode 0.2.2 · Windows 测试版

本版继续把 ZCode 工作区能力接到 DeepSeek Harness 会话，并为 Dcode 安装版接入 GitHub Releases 自动更新。安装包仍未签名，Windows 可能提示“未知发布者”。

## 本版重点

- **GitHub 自动更新**：启动后及运行期间检查 `ningbainb/Dcode` 的正式发行版；发现新版本后可从现有更新入口下载、查看进度，并在确认后重启安装。设置中的自动下载选项继续可用。更新器使用同一发行版附带的 `latest.yml` 和安装包校验信息。
- **DSH 设置与会话衔接**：模型供应商设置扩展到自定义供应商、模型和密钥；ZCode 会话可导入 Dcode，并保留原始记录供核对。新增的 DSH 会话标注、插件入口及工作区衔接见仓库中的专项说明。
- **界面**：保留 ZCode 桌面工作区风格及 Dcode 图标；更新弹窗在 Dcode 中可用，未建立预览发行流的开关不再出现。

## 下载与升级

下载 `Dcode-Setup-0.2.2-x64.exe`。首次从 v0.2.1 升级需要手动运行本版安装包：v0.2.1 当时关闭了更新器，其 GitHub 发行版也没有 `latest.yml`，无法自行发现 v0.2.2。安装本版后，后续正式发行版可通过应用内更新入口获取。

同时发布 `latest.yml` 和安装包，二者必须来自同一次构建；`Dcode-Setup-0.2.2-x64.exe.blockmap` 用于差分下载。安装包大小 **582,849,376 字节**，SHA-256：

`33ecadc0588b6341f76ba99665aa16d4e1f572bf915b33b8fbe3462f6ac371dc`

`Dcode-0.2.2-SHA256SUMS.txt` 还列出 blockmap 与 `latest.yml` 的校验值。

## 验证边界

本版需要分别核对源码检查、桌面烟测、安装包内 DSH runtime、更新元数据及实际安装体验。GitHub 尚无高于 v0.2.2 的正式发行版时，线上无法完成“下载更高版本并安装”的真实更新演练；此项应在下一个版本发布时验收。
