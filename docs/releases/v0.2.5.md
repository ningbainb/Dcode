# Dcode 0.2.5 · Windows 测试版

本版将 ZCode 设置页里的 Markdown 自定义命令接入 DSH 会话。安装包继续通过 GitHub Releases 提供自动更新，仍未签名，Windows 可能提示“未知发布者”。

## 本版重点

- 在 DSH 聊天框输入已保存的 `/命令名 参数`，会按当前项目的命令目录和设置开关读取模板，再交给 DSH 会话执行。
- 支持 `$ARGUMENTS`、`$1` 等参数替换；没有占位符时把参数附在模板末尾。项目命令优先于用户命令。禁用的命令或插件命令不会作为模板发送，失败时保留草稿。
- 使用动态 shell 展开的旧命令会明确报错。Dcode 不在界面进程执行这类片段，避免绕开 DSH 工具审批。ZCode 的命令钩子尚未桥接。
- 保留 0.2.4 的 ZCode 技能接入、DSH 模型供应商设置和 GitHub 云备份。

## 下载与升级

已安装 0.2.2 或更新版本的用户可通过应用内“检查更新”获取本版。0.2.1 用户需先手动安装 0.2.2 或更新版本一次。`Dcode-Setup-0.2.5-x64.exe` 是 Windows x64 安装包；同一 Release 的 `latest.yml` 与 `.blockmap` 供更新器校验和差分下载。

安装包大小 **582,946,374 字节**（约 556 MiB），SHA-256：`e9894140466da019ad8351afaa528cea13e82b8dbc652fa48447658e20d28ac9`。`Dcode-0.2.5-SHA256SUMS.txt` 列出安装包、`.blockmap` 和 `latest.yml` 的校验值。签名状态为 `NotSigned`。

## 验证边界

本地合成模型夹具用于验证从 ZCode 命令文件、启用设置、Dcode 输入框到 DSH 模型请求的链路，也验证了禁用后的拦截。解包版通过启动、会话恢复、运行时重启、停止继续、工具输出、Git/终端和“检查更新”菜单烟测。发布后以隔离数据目录启动 0.2.4 解包应用，已从 GitHub 发现“新版本 0.2.5”。这不代表第三方在线模型账号、所有插件命令或动态 shell 命令已验收；更新下载与覆盖安装尚未执行。
