# Dcode 0.2.4 · Windows 测试版

本版将 ZCode 的工作区和用户级技能接入 DeepSeek Harness（DSH）的原生技能目录与 `skill` 工具，同时扩展 DSH 模型供应商设置，并继续通过 GitHub Releases 提供自动更新。安装包未签名，Windows 可能提示“未知发布者”。

## 本版重点

- **ZCode 技能可在 DSH 会话使用**：DSH 读取项目 `.zcode/skills` 和用户 `~/.zcode/skills`，不复制或改写技能文件。技能目录按工作区选择，模型可看到摘要并通过原生 `skill` 工具加载正文。
- **设置开关真正生效**：ZCode 技能设置页写入的禁用状态被 DSH 读取；文件监视器在新增、修改或禁用后刷新目录。现有 DSH `.dsh/skills`、`.agents/skills` 仍由 DSH 管理。
- **模型供应商设置更完整**：沿用 ZCode 的双栏、独立 API 模板和模型编辑样式，可配置多模型、排序、密钥、上下文与输出上限。高级设置新增图片输入声明、推理档位与接口值，并保存到 DSH Profile；ZCode 自带供应商、Z.ai/BigModel 套餐入口不在此目录。
- **兼容边界**：不符合 DSH kebab-case 命名的技能会转成稳定的调用名，原名称留在描述中。ZCode 插件扩展中的技能以及记忆、自动化、钩子、子智能体设置尚未整体接入。

## 下载与升级

已安装 v0.2.2 或 v0.2.3 的用户可通过应用内“检查更新”获取本版。v0.2.1 用户需要先手动安装 v0.2.2 或更新版本一次。下载 `Dcode-Setup-0.2.4-x64.exe`；同一 Release 的 `latest.yml` 与 `.blockmap` 供更新器校验和差分下载。

安装包大小 **582,933,638 字节**（约 556 MiB），SHA-256：`43532c96776512096eb3323177136cc604298922a5e1ad4d0546256de83eeb04`。`Dcode-0.2.4-SHA256SUMS.txt` 列出安装包、`.blockmap` 和 `latest.yml` 的校验值。本版仍未进行代码签名。

## 验证边界

本地合成模型夹具证明 DSH 会向模型展示 ZCode 技能目录、可调用原生 `skill` 工具读取正文，并在禁用后从下一会话目录移除；模型供应商设置通过 DSH Profile 保存/回读和 Electron 操作验收。解包版通过启动、会话、工具输出、运行时重启与 Git 查看冒烟测试。以上不代表所有第三方技能脚本或真实在线模型账号均已验证。GitHub 端资产完整性以及旧版到本版的更新发现，应以发布后的实际测试为准。
