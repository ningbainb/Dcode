# Dcode 0.2.7 · Windows x64 测试版

本版继续把 ZCode 工作区能力接入 DSH 0.1.7-alpha.2 的原生会话协议。

- 聊天支持 PNG、JPEG、WebP、GIF 图片和普通文件；普通文件通过 DSH 上传回执进入同一会话，Agent 可用原生 `read` 工具读取。附件引用随 DSH 会话历史恢复。
- 当前用户 `~/.zcode/AGENTS.md` 会同步至 Dcode 私有 DSH Home，由 DSH 原生指令加载器处理；同一会话的下一条提示可感知文件修改或删除。Dcode 保留私有 DSH 文件中已有的非托管内容。
- DSH 运行时部署缓存按系统和 CPU 架构隔离，打包校验按平台定位应用资源目录。这是后续 macOS/Linux 适配的基础；本版仅验收 Windows x64。
- 继续通过 `ningbainb/Dcode` 的 GitHub Releases 提供应用内更新；下载后由用户确认安装。

本版需在本地安装包构建、真实桌面烟测、SHA-256 和 GitHub 发布元数据验证完成后才可作为公开发行版。安装包未签名，Windows 可能显示“未知发布者”。
