# Dcode 0.2.7 · Windows x64 测试版

本版继续把 ZCode 工作区能力接入 DSH 0.1.7-alpha.2 的原生会话协议。

- 聊天支持 PNG、JPEG、WebP、GIF 图片和普通文件；普通文件通过 DSH 上传回执进入同一会话，Agent 可用原生 `read` 工具读取。附件引用随 DSH 会话历史恢复。
- 当前用户 `~/.zcode/AGENTS.md` 会同步至 Dcode 私有 DSH Home，由 DSH 原生指令加载器处理；同一会话的下一条提示可感知文件修改或删除。Dcode 保留私有 DSH 文件中已有的非托管内容。
- DSH 运行时部署缓存按系统和 CPU 架构隔离，打包校验按平台定位应用资源目录。这是后续 macOS/Linux 适配的基础；本版仅验收 Windows x64。
- 继续通过 `ningbainb/Dcode` 的 GitHub Releases 提供应用内更新；下载后由用户确认安装。

Windows x64 安装包 `Dcode-Setup-0.2.7-x64.exe` 已作为 [GitHub Release v0.2.7](https://github.com/ningbainb/Dcode/releases/tag/v0.2.7) 发布。大小为 **622,635,252 字节**，SHA-256 为 `8723cf1749cf3b6e52fafaa3d0901b2c886ceb8cb68c801e7def725d30eb7d5a`；同一 Release 的 `Dcode-0.2.7-SHA256SUMS.txt` 还列出 blockmap 与 `latest.yml` 的校验值。安装包未签名，Windows 可能显示“未知发布者”。

本地发行校验通过版本、`latest.yml` 的 SHA-512、GitHub feed、随包 Node 24.14.0 和 DSH 物理运行时；解包应用桌面烟测通过工作区、DSH 会话与工具、图片和文件、默认沙箱 ACL 修复、会话恢复、Git Diff 和终端。隔离的 v0.2.6 应用还从公开 GitHub Release 完整下载本版安装包、进入 `update-downloaded`，落盘 SHA-256 与上述值一致。用户确认后的实际安装与重启尚未在隔离系统中验证；第三方在线模型账号未逐一实测。
