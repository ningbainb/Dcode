# Dcode 0.2.1 · Windows 测试版

首个公开下载的 Dcode Windows x64 安装包。**这是未签名的测试构建**；Windows 可能显示“未知发布者”或 SmartScreen 提示。请核对下方 SHA-256，并在自己可控的环境中试用。

## 本版内容

- **GitHub 私有云备份**：通过浏览器登录账号，为本地 Git 项目预览文件后开启备份；已保存到磁盘的暂存、未暂存和未跟踪修改会进入独立快照。支持应用运行期间的定时检查、手动备份、查看差异和恢复到新目录。备份目标必须是用户自己名下的私有 Dcode 备份仓库，不改变原项目提交记录。[使用范围与步骤](../CLOUD-BACKUP.md)
- **ZCode 工作区 × DeepSeek Harness**：DSH 驱动模型、会话、消息流、工具与权限；Dcode 将任务列表、聊天、文件、终端和 Git/Diff 接到同一桌面工作区。支持多会话、项目切换、停止与继续、重启后恢复。[融合边界](../DSH-INTEGRATION.md)
- **Dcode 界面与图标**：重新设计新任务页、输入区和可展开的工具执行记录，精简本地设置导航，并使用新的 Dcode 图标与品牌。

## 下载与校验

下载 `Dcode-Setup-0.2.1-x64.exe`，并用随附的 `Dcode-0.2.1-SHA256SUMS.txt` 校验。安装包大小为 **659,594,045 字节**，SHA-256：

`13024f0a71c5af62bab07b2ef5cbeabf3059d887b46eeae0f37950bc155965d9`

Windows PowerShell 可运行：

```powershell
Get-FileHash .\Dcode-Setup-0.2.1-x64.exe -Algorithm SHA256
```
